03 RAG 컨텍스트 미리보기
GET /notes/context · —
노트를 저장하면 LLM 프롬프트에 바로 붙여넣을 수 있는 축약 텍스트가 생성됩니다.
API — 목록 GET /notes/records?profile=…&q=…&category=… · RAG 컨텍스트 GET /notes/context?profile=… (보관 노트 제외, 카테고리별 그룹) · 생성 POST /notes/records · 수정 PUT /notes/records/{id} · 삭제 DELETE /notes/records/{id}. 보관(archive)한 노트는 목록 하단에 남지만 컨텍스트에서는 빠집니다 — 더 이상 유효하지 않은 사실은 지우지 말고 보관하세요.
